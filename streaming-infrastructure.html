npm、pip 安装慢：开发者镜像与代理的设置

发布于 2026年11月12日 | 开发环境

一、先判断慢在哪里

安装命令卡住时，先看是下载速度慢，还是连接超时。前者可以换镜像源，后者可能需要借助代理。

二、使用镜像源

npm 与 pip 都支持修改下载源地址，指向较近且更新及时的镜像站。修改后重新安装，通常速度会明显提升。注意镜像的同步会有延迟，最新发布的包可能暂时没有。

三、为工具设置代理

  • npm 可通过配置项设置 proxy 与 https-proxy。
  • pip 可通过命令参数或配置文件指定代理。
  • 设置时确认端口与协议类型与客户端一致。

四、团队里的统一做法

把镜像与代理配置写进项目文档或 CI 配置里，避免每个人各自摸索。同时锁定依赖版本，让安装结果更可复现。

五、安全提醒

只使用可信的镜像源，并留意依赖包的来源。不要随意执行来历不明的安装脚本。
